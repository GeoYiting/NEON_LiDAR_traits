Run the code in sequence to 
preprocess and voxelate the point cloud (1), 
filter data based on photosynthetically active radiation (PAR) and plant area density profile (PADP) (2), 
calculate accumulated plant area density (APAD) and leaf area index (LAI) from the tree crown top (3),
